Публичные испытательные материалы: без клиентских данных и секретов.

  1. 01Разрешите конкретный originДоверенный сценарий явно задаёт https://lab.neonplatform.online. Сам URL не заменяет полномочия.
  2. 02Сохраните исходный ответСопоставьте конечный URL, HTTP status, время получения и SHA-256 тела с evidence отчёта.
  3. 03Проверьте выводы независимоИспользуйте зафиксированный Git commit и локальные ожидания. Публичный JSON — справочник, а не единственный источник истины.
  4. 04Оставьте решение человекуПроверьте findings и ограничения. Черновик сохраняет статус not_independently_verified.
